# Creation Handoff — web-business-pipeline 1.0.0

## Outcome

- Generalized the former game-site suite into the governed `web-business-pipeline`; the migration is a hard cut with no old IDs, aliases or wrappers.
- Kept opportunity discovery upstream and method-specific. `game-keyword-radar` remains only an optional Steam/Roblox adapter, not the central entrypoint.
- Added candidate contract v2 with stable `<namespace>:<slug>` keys, provider-neutral identities, explicit upstream qualification checks and a structured business hypothesis.
- Added seven JSON Schema contracts, six editable templates and one standard-library Python CLI.
- Added semantic gates for page intent ownership, two-source coverage, current-trusted claims, cross-file references, content hashes, full current-change-batch human review, old-domain residue, local checks, rollback, explicit external authorization, HTTP/provider readback and no-data growth decisions.
- The bundled CLI performs no network request and no external action.
- Added ten discoverable `web-business-*` stage Skills with one shared CLI/state contract, explicit artifact ownership, initial-build routing, hold review, and grow optimization/expansion re-entry.
- Integrated the user-supplied 龙猫 commercial-validation method as a cross-stage evidence layer rather than another lifecycle state: `search_growth`, `conversion_learning` and `commercial_scale` remain distinct.

## Adopted, adapted, rejected and invented

- Keep: unique-value pages, staged content artifacts, command routing, real Google readback, and 龙猫方法里的客户、问题、价值、商业模式、最高风险假设、主要指标与事件层级。
- Adapt: stage completion uses cross-file evidence rather than file existence; commercial validation is recorded as three evidence levels, while Google configuration, indexing and performance remain separate facts.
- Reject: bulk thin-page generation, default external autonomy, Skill-local runtime state, heavyweight SWOT/PESTLE, invented scores, locale-specific SEO templates as global rules, and Google Indexing API for ordinary content pages.
- Invent: provider-neutral identity, upstream qualification checks, `standard|current_trusted` claim policy, per-action permission ledger, old-domain scan and a scheduled no-data hold branch.
